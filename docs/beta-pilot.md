# 初期プロフェッショナル試用

状態: 準備。募集・送信・公開・参加者登録は未実施。11/16 開始予定（下の「日程と決定」）。

仮説: 日加をまたぐ事業開発・市場進出の担当者は、政府・企業・研究機関の発表を追い、原文を確認して顧客説明や案件判断に使うために再訪する。日加専用フィードの新設は前提にしない。

## 実施条件

重大な保存・根拠表示の不具合を解消し、原文到達・保存・引用・情報源選択を実操作で確認してから試用版を提示する。取得不能な情報源や対象範囲の限界も説明する。

目安は5人、開始日から14日。人数は需要の推計ではない。候補者の選択・連絡は別途実施する。閲覧履歴・関心設定・顧客名・機密案件の収集は不要。記録は参加者の同意を得て匿名IDとし、実際の業務内容は公開情報で説明できる範囲に限る。

政府職員（大使館・総領事館・JETRO・自治体など）は初回の候補から外す（2026-10-30 決定）。理由: 運営者が無償の助言で関わっている相手に試用を頼むと助言と売り込みが混ざる。運営者が受託を狙う場合は利害関係者からの無償の役務提供として国家公務員倫理規程に触れるおそれがある［要確認］。政府機関の料金の扱いも未決（BACKLOG）。この試用の結果が出て、政府機関の料金と倫理面の確認が済んでから改めて判断する。それまでは、運営者が政府側に出す資料の事実確認に Sivree を使い、相手から聞かれたときだけ紹介する。

## 最初の操作

1. 仕事で追っている公開テーマを一つ選び、日本・カナダと必要な情報源を設定する。
2. 関連する発表を探し、発信主体・日付を確認して原文を開く。
3. 使いたい発表を保存し、引用をコピーする。設定を開き直す。

操作支援なしで完了したか、迷った箇所、原文までの時間を記録する。見つからなかった場合も記録し、架空の有用事例で補わない。

## 価値の確認

| 時期 | 聞くこと | 証拠 |
|---|---|---|
| 初日 | 何を追う仕事に使うか。設定と原文確認は自力でできたか | 成否・時間・障害 |
| 7日目 | 翌週も仕事で使ったか。従来の収集方法から何が変わったか | 自己申告と具体例（未回答は不明） |
| 14日目 | 判断・調査・説明に使えたか。なくなると何が困るか。何に組織として払うか | 公開可能な事例・代替手段・購入条件 |

暫定判断: 5人中3人以上が翌週も業務利用し、2人以上に具体的な利用例があれば同じ用途の募集を続ける。未達なら、価値不足・情報源不足・操作障害を区別し、最も頻出した原因を一件改善して再試用する。小標本なので市場適合や収益性の証明とはしない。

## 訴求とデモの準備

紹介ページの中心メッセージ案: 「日加の事業動向を、政府・企業・研究機関の発表から直接追う。出所を確かめ、仕事の判断材料にする。」

公開前のデモは、実在する公開発表を使い、情報源選択→一覧→原文→保存→引用を60〜90秒で示す。出所を確認できることと、発表内容の真実性を保証することを区別する。映像・公開ページ・募集文面の外部提供は未実施。

結果記録欄: 匿名ID / 開始日 / 初回操作成否 / 7日目利用 / 具体的な利用例 / 障害 / 代替手段 / 料金に関する発言 / 次の改善。参加者確保前に数値を埋めない。
